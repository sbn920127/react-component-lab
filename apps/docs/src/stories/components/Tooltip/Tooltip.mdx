# Tooltip 工具提示

用於顯示元素的輔助資訊，通常在滑鼠懸停 (Hover) 或鍵盤聚焦 (Focus) 時出現。

## 設計原則
- **黑暗風格**：預設使用黑底白字 (`bg-slate-900`, `text-slate-50`)，提供高對比度。
- **無障礙 (A11y)**：
  - 支援 `Tab` 鍵聚焦觸發。
  - 支援 `ESC` 鍵關閉。
  - 自動設置 `role="tooltip"`。
- **定位**：自動翻轉 (Flip) 與邊界檢測 (Shift)。

## 使用範例

### 基礎用法

```tsx
import { Tooltip, Button } from '@react-component-lab/ui';

<Tooltip placement="top" delay={200}>
  <Tooltip.Trigger asChild>
    <Button>Hover Me</Button>
  </Tooltip.Trigger>

  <Tooltip.Content>
    <p>Add to library</p>
    <Tooltip.Arrow />
  </Tooltip.Content>
</Tooltip>
